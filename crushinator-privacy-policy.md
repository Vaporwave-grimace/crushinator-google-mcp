# Privacy Policy — Crushinator Google MCP

Effective date: November 17, 2026

Crushinator Google MCP is a personal, single-user software application
operated by its owner ("the Owner") for the Owner's own use. It runs
entirely on the Owner's own computer and connects to the Owner's own
Google account using Google's OAuth authorization.

## What data the application accesses

With the Owner's consent, the application accesses:

- Gmail messages and labels (read, label, draft, and send on the
  Owner's behalf)
- Google Drive files and folders (read, download, and upload on the
  Owner's behalf)

This access is granted through Google OAuth scopes (gmail.modify,
gmail.send, and drive) and can be revoked by the Owner at any time at
https://myaccount.google.com/permissions

## How the data is used

Data accessed through Google APIs is processed locally on the Owner's
computer solely to carry out actions the Owner requests through the
application. The application has no other users, no server component,
and no remote backend.

## Sharing and disclosure

Google user data is never sold, never used for advertising, never
transferred to third parties, and never read by any human other than
the Owner. The application does not transmit Google user data off the
Owner's computer.

## Data storage and retention

The application stores only the following, locally on the Owner's
computer: an OAuth credential token (so the Owner is not asked to
re-consent on every run) and a local audit log of tool calls
(timestamps, tool names, and result status — no message bodies). Both
are retained until the Owner deletes them or revokes access.

## Limited Use

Crushinator Google MCP's use and transfer to any other app of
information received from Google APIs will adhere to the Google API
Services User Data Policy, including the Limited Use requirements.
